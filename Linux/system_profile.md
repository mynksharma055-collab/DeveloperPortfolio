## 2. Binary Number Representation

### Decimal to Binary Conversion: 75

75 / 2 = 37 remainder 1
37 / 2 = 18 remainder 1
18 / 2 = 9 remainder 0
9 / 2 = 4 remainder 1
4 / 2 = 2 remainder 0
2 / 2 = 1 remainder 0
1 / 2 = 0 remainder 1

Reading remainders from bottom to top:

75 (Decimal) = 1001011 (Binary)

### Binary to Decimal Conversion: 110101

110101 = 1×2^5 + 1×2^4 + 0×2^3
       + 1×2^2 + 0×2^1 + 1×2^0

= 32 + 16 + 0 + 4 + 0 + 1

= 53 (Decimal)

### Why Computers Use Binary

Computers use binary because digital electronic circuits
can easily represent two states: ON (1) and OFF (0).
